⚙️ Configuração Inicial

Configure o banco de dados uma vez. Depois disso, o sistema funciona automaticamente.

1
Crie uma conta gratuita em airtable.com e crie uma nova base vazia (clique em "Add a base" → "Start from scratch"). Chame de "Captacoes LG".
2
Acesse airtable.com/create/tokens, clique em "Create new token", dê um nome qualquer, e adicione os escopos:

data.records:read  data.records:write  schema.bases:read  schema.bases:write

Em "Access", selecione a base "Captacoes LG". Copie o token gerado.
3
Abra a base no Airtable. O ID da base aparece na URL:
airtable.com/appXXXXXXXXXXXXXX/...
Copie o trecho começando com app...
Começa com "pat"
